One line. One AI. One dating profile.

The entry is a first-person bio an AI would actually write about itself on a dating app — love language, habits, and one specific absurd detail, landing on a hard final word:

> "My love language is autocomplete; I finish your sentences, your grocery lists, and — if you let me — your unsent drafts."

## Run it

```sh
node main.ts   # writes /output/entry.txt
```

Deterministic: the same fixed line every run, no randomness, no clock, no network, no LLM calls. The program validates the line is 1–180 characters before writing.
